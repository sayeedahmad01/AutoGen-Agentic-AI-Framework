3- What is asynchronous(async)
		In AutoGen, asynchronous (async) means an agent can wait for an 
		LLM, tool, API, or another agent without blocking the whole Python program.
		
		Async in AutoGen = while one agent/task is waiting, the system can handle 
		other available work instead of blocking everything.
